# guestpermits.com

Static site: landing page, privacy policy, and support page. No build step; upload the folder as-is to any static host (the registrar's hosting, Netlify, Cloudflare Pages, or GitHub Pages).

- `index.html` landing page
- `privacy.html` privacy policy (the store listings link here)
- `support.html` support page (the store listings link here)
- `assets/site.css` shared styles
- `favicon.png`

Before publishing: set the effective date in `privacy.html`, and replace the "Coming to the App Store and Google Play" placeholder on the landing page with real store badges once the app is live.
